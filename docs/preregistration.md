# 사전 등록: 연구 질문, 가설, 판정 기준

이 문서는 실험 결과를 보기 전에 적어 둔 연구 질문, 가설, 성공 기준, 판정 규칙을 모은 것이다. 원본은 저장소 밖에서 관리한 계획 문서이고, 2026-10-31에 그 문서에서 가설과 판정 기준에 해당하는 부분만 옮겼다. 각 절의 날짜는 계획 문서에 적힌 기록 시점이다. 저장소의 커밋 이력은 모두 그 뒤에 시작됐으므로 날짜를 git으로 증명하지는 못한다. 결과와 판정은 `reports/tables/`의 표와 README에 있다.

원칙은 세 가지였다. 실험마다 대응하는 연구 질문과 예상 방향을 미리 적는다. 비-VLM 기준선(B1)이 더 좋게 나와도 그대로 보고한다. 최종 설정은 학습 측 안의 검증 집합(inner-val)으로만 정하고 held-out 결과를 본 뒤에는 바꾸지 않는다.

## 1. 연구 질문과 가설 (2026-10-24, 첫 학습 전)

| 연구 질문 | 질문 | 가설 | 검증 실험 |
|---|---|---|---|
| RQ1 진단 이득 | 강한 탐지기(SALAD)가 있을 때 LoRA를 적용한 VLM이 비-VLM 진단기(B1)보다 결함 진단을 개선하는가 | 그룹 정확도는 비슷하고, 개수나 구성 같은 논리 결함의 세부 정확도에서만 앞선다 | B0, B1 대 Ours, 결함 유형별 분해 |
| RQ2 입력 단서 | 정상 참조 이미지, 이상 영역 crop, 규격 텍스트는 각각 어떤 결함 유형에 기여하는가 | 참조와 규격은 논리 결함(개수, 배치)에, crop은 작은 구조 결함에 기여한다 | 입력 제거 실험(ablation)의 쌍대 차이와 95% 신뢰구간, 논리와 구조 분리 |
| RQ3 미등록 결함 | 학습 중 결함 목록 일부를 지우는 "목록 드롭아웃"이 미등록 결함에 "미분류"로 답하고 내용을 서술하게 하는가 | 드롭아웃 없이 학습하면 미등록 결함을 기존 그룹으로 잘못 분류한다 | open-set 실험, 드롭아웃 유무 비교 |
| RQ4 거부 단계 | 이상 비율 1%일 때 VLM의 오탐 거부 단계가 재현율 손실보다 큰 오경보 감소를 내는가 | 거부 단계가 재현율을 1%p 이하로 잃으면서 오경보를 절반 이상 줄인다 | 탐지기 단독 대 캐스케이드의 FPR과 재현율, 이상 비율 보정 곡선, VLM 단독(B2) |

결과: `reports/tables/m3_summary.md` 7절과 README "연구 질문과 판정". RQ1 기각, RQ2는 crop만 지지, RQ3는 방향 일치이나 효과 작음, RQ4 미충족.

## 2. 성공 기준 (2026-10-24)

두 held-out fold의 예측을 합산해 평가한다.

- 탐지: SALAD 재현 image AUROC가 보고치 96.1 대비 2%p 이내.
- 설명(정답 이상 이미지만 입력하는 oracle 게이팅): 결함 그룹 Top-1 85% 이상, 논리/구조 구분 90% 이상, 형식 준수 99% 이상, zero-shot 대비 유의한 개선(McNemar p<0.05). B1과의 비교는 방향과 무관하게 보고한다.
- 종단: Ours의 종단 F1이 VLM 단독(B2)과 같거나 높을 것. test 셋의 이상 비율(63%)은 실제 라인보다 훨씬 높으므로 VLM 호출률을 π·TPR + (1-π)·FPR로 π = 1%, 5%, test 비율 각각에 대해 환산해 보고한다(목표: 정상 이미지의 VLM 호출 10% 이하).
- 지연(RTX 3060): 탐지기 100ms/장 이하, VLM은 이상 이미지 1장당 4B QLoRA 6초 이하, 2B 병합 모델 3초 이하.

결과: `reports/tables/m3_summary.md` 7절. 그룹 85%와 유형 90%는 미달, 형식 99%와 zero-shot 대비 유의 개선은 충족, 종단 F1은 B2보다 높음, 호출률 목표는 미달.

## 3. 평가 설계와 통계 (2026-10-24)

- 두 held-out fold의 예측을 합쳐 계산하고, 각 이미지는 자기를 학습하지 않은 모델의 예측으로 채점한다.
- 주요 비교는 같은 이미지로 짝지은 paired bootstrap 95% 신뢰구간과 McNemar 검정. 입력 제거 실험은 Holm 보정. fold가 2개라 fold 간 표준편차는 보고하지 않는다.
- 입력 제거 실험 규칙: seed 반복은 주력 설정에만 한다. 제거 실험은 fold 0, 단일 seed, 2B 모델로 선별하고, 효과의 절댓값이 큰 상위 2개만 4B 모델과 두 fold로 확인한다. 4B 확인에서 그룹 전체 쌍대 차이의 95% 신뢰구간이 0을 제외하면 재현으로 본다.
- 입력 제거 실험별 예상 방향(2B 선별, 적용에서 미적용을 뺀 효과가 양수이면 그 입력이 기여):

| 실험 | 대응 연구 질문과 예상 | 판정 부분집합 |
|---|---|---|
| 정상 참조 제거 | RQ2: 참조는 논리 결함(개수, 배치)에 기여 | 논리 결함 |
| crop 제거 | RQ2: crop은 작은 구조 결함에 기여 | 구조 결함 |
| 규격 텍스트 제거 | RQ2: 규격은 논리 결함(개수, 배치)에 기여 | 논리 결함 |
| 탐지기 텍스트 제거 | 예상 없음 | 없음 |
| 정상 네거티브 제거 | RQ4: 오탐 거부 학습(정상 거부율) | 정상 이미지 |
| 목록 드롭아웃 제거 | RQ3: open-set 표에서 검증 | 없음 |
| 비전 인코더 LoRA 추가 | 작은 부품의 개수 세기에 필요 | 개수 계열 결함 |

- open-set 실험: 구조형은 모든 카테고리의 이물 혼입(123장)을, 논리형은 카테고리별 1개 그룹(과일 구성 수량, 과일 아이콘, 칸막이 누락, 나사 길이, 케이블 색상)을 학습 데이터와 프롬프트 목록에서 제외한다. 지표는 제외 그룹의 미분류 응답률, 알려진 그룹의 과잉 미분류율, 자유 서술의 핵심어 일치율.
- 성공과 실패 사례는 각 모델이 학습하지 않은 held-out 이미지에서만 고른다. 사례 선택 규칙은 `src/report/m4_figures.py` 머리말에 고정했다.

결과: `reports/tables/m3_summary.md` 1절과 2절(입력 제거 실험), 3절(open-set).

## 4. 추가 실험 1: 모델 크기와 라벨 수 (2026-10-29 01시, 결과 전)

목적은 핵심 음성 결과(Ours 4B 그룹 정확도 55.7이 B1 67.0보다 낮음)의 원인 후보 두 가지, 모델 용량과 학습 라벨 수를 검증하는 것이다. 둘 다 추가 실험으로 따로 보고하고 Ours의 주력 결과와 설정은 바꾸지 않는다.

- 모델 크기: Qwen3-VL-8B-Instruct를 QLoRA(NF4)로 학습하고 다른 설정은 4B 주력과 같게 둔다(같은 데이터, r=16, epoch 3, seed 0, 두 fold).
  - 가설: 8B의 그룹 정확도가 4B seed 0보다 높다(두 fold 합산 993장, paired bootstrap과 McNemar). B1과의 격차가 닫히는지는 방향을 정하지 않고 보고한다.
  - 판정: 차이가 0보다 크고 p<0.05이면 지지. 8B가 4B seed 3개의 범위(55.4~56.2) 안이면 "용량이 병목이 아님"으로 해석한다. 지연과 최대 VRAM을 함께 보고한다.
- 라벨 수 곡선: 2B LoRA를 fold 0 학습 측의 라벨 25%와 50%로 학습해 fold 1 이미지로 평가한다(100%는 기존 2B 모델). 층(역할, 카테고리, 정상/그룹)별로 줄이고 층마다 최소 1장을 남기며 비율 간에 중첩한다(25 안에 50 안에 100). epoch 3 고정. B1도 같은 부분집합으로 학습한다.
  - 가설: VLM의 그룹 정확도는 라벨 수에 따라 증가하고 50%에서 100%로 늘려도 증가한다(포화 전). 라벨 2배당 증가폭이 B1보다 크면 데이터 부족을 격차의 한 원인으로 해석한다.
  - 판정: 인접 비율의 쌍대 차이(McNemar)와 2배당 증가폭(%p). 결함 종류(개수 계열, 기타 논리, 구조)별로도 분해한다.

결과: `reports/tables/p2_summary.md`. 8B는 4B와 차이 없음, 라벨 수 곡선은 두 모델이 평행.

## 5. 추가 실험 2: 캐스케이드 심판 교체 (2026-10-30, 결과 전)

동기는 RQ4 미충족(재현율 손실 4.0%p)의 직접 원인이 판정 구간에서 VLM이 이상 143장 중 28.0%를 잘못 거부하고 정상 118장 중 69.5%만 거부한 데 있다는 점이다. B1은 같은 입력으로 정상 클래스의 확률을 낸다.

- 설정 J1(주): 판정 구간(τ_low 이상 τ_high 미만)의 거부 결정을 B1의 argmax("good"이면 거부)로 대체한다. 통과 구간과 설명 구간의 규칙은 그대로다. B1이 이상이라 한 판정 구간 이미지는 설명 구간과 같은 규칙으로 VLM 출력을 쓴다. 매개변수는 없다.
- 설정 J2(부, 탐색): B1의 p(good) 임계값을 fold 학습 측의 5-fold 교차 예측(out-of-fold) 확률에서 "판정 구간 이상의 97%가 통과"하도록 정한다(held-out 미사용).
- 가설 J: J1은 VLM 심판 대비 재현율 손실이 1%p 이하로 줄고 오경보 감소 50% 이상을 유지한다(RQ4 기준 충족). 종단 정답 그룹 F1은 VLM 심판 이상이다.
- 판정: Ours 4B seed 0, 1, 2 각각에서 RQ4 기준 충족 여부, J1에서 VLM 심판을 뺀 종단 그룹 F1의 층화 paired bootstrap 95% 신뢰구간, VLM 호출률(이상 비율 1%, 목표 10%). held-out은 1회만 평가하고 결과 후 규칙과 임계값을 바꾸지 않는다. 표1은 그대로 두고 별도 표로 보고한다.

결과: `reports/tables/m3_cascade_b1judge.md`. 가설 J 미충족(오경보는 더 줄지만 재현율 손실이 커짐).

## 6. 추가 실험 3: 입력 표현 (2026-10-30, 결과 전)

동기는 추가 실험 1에서 용량과 라벨 수가 배제된 뒤 남은 격차 후보가 장면 전체 구성 결함의 입력 표현이라는 점이다(VLM은 B1이 쓰는 SALAD 구성 점수를 보지 못한다). 근거: 기타 논리 결함 392장에서 60.3 대 80.6, 칸막이 누락 2.6 대 100, 케이블 길이 47.2 대 100인 반면 개수 계열은 64.3 대 64.5로 같다.

- 변형 A(구성 신호): 프롬프트의 탐지기 줄에 SALAD 세 항(국소, 전역, 구성)의 학습 측 정상 대비 백분위를 추가한다.
- 변형 B(B1 후보 힌트): "[분류기 후보] <그룹> p, <그룹> p" 형식으로 상위 2그룹을 넣는다(클래스 확률을 그룹으로 합산, 정상 포함). 학습 측 기록은 5-fold 교차 예측 확률, held-out은 학습 측 전체로 학습한 B1 확률을 쓴다. VLM의 역할이 검증과 설명 계층으로 바뀌는 실험이므로 결과가 좋아도 "VLM 단독 진단"의 개선으로 쓰지 않는다.
- 절차: 입력 제거 실험과 같은 2단계 틀. 2B를 fold 0으로 학습해 fold 1 이미지에서 선별하고(기준은 기존 2B 모델, paired bootstrap과 McNemar, 논리와 구조 분해에 Holm 보정), 그룹 전체 효과가 양수이고 가장 큰 변형 1개를 4B 두 fold로 확인한다(기준 Ours 4B seed 0). 둘 다 0 이하이면 4B 확인을 생략한다.
- 가설 A: 변형 A는 기타 논리 결함에서 그룹 정확도를 올린다(2B 선별에서 기타 논리 효과가 0보다 크고, +5%p 이상이면 지지).
- 가설 B: 변형 B는 2B에서 B1과의 격차(fold 1 이미지 65.5 - 43.3 = 22.2%p)를 절반 이상 줄인다.
- 부가 지표: 변형 B의 힌트 1위와 출력이 같은 비율, 힌트 1위가 틀린 이미지에서의 정답률(복사 여부 진단), 정상 거부.
- 4B 확인 판정: 그룹 전체 쌍대 차이의 95% 신뢰구간이 0을 제외하고 양수면 재현. 결과 후 설정 변경 없음. 표1에 별도 행(P3)으로 추가한다.

결과: `reports/tables/p3_summary.md`. 가설 A 지지 안 됨, 가설 B 지지(4B에서도 재현). 출력의 77%가 힌트 1위와 같아 VLM 단독 진단의 개선으로 보지 않는다.

## 7. 결과를 본 뒤에 한 비교 (사전 등록 아님)

아래는 결과를 본 뒤에 계산한 것이라 탐색적 수치로만 적는다.

- open-set 논리형에서 드롭아웃 모델의 알려진 결함 그룹 정확도가 낮은 것(`reports/tables/m3_summary.md` 3절).
- 두 open-set 실험의 불일치 쌍을 합친 검정(사전 등록이 아니라 판정에 쓰지 않음).
- 심판 교체 실험에서 VLM과 B1이 둘 다 정상이라 할 때만 거부하는 조합(`reports/tables/m3_cascade_b1judge.md`).
- 입력 표현 실험 4B 확인에서 B1과의 직접 비교(`reports/tables/p3_summary.md` 2절).
